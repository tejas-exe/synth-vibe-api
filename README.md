🎵 SyncPlay

Watch Together. Listen Together. Share Together.

SyncPlay is a real-time collaborative mobile application that allows friends to create or join private rooms to enjoy videos, music, and screen sharing together. The app keeps everyone in sync while providing a clean, modern, and distraction-free experience.

✨ Features
🎉 Create or Join Rooms using a unique room code
👥 Unlimited participants (minimum 4 to start)
📺 Real-time Screen Sharing
🎥 Watch videos together inside the app
🎵 Synchronized Music Listening
🎤 Presenter Selection
💬 Live Chat & Reactions
🔄 Automatic DJ Rotation (Switch Mode)
🎧 Manual Music Mode
⚡ Low-latency synchronization
🔐 Private & Secure Rooms
📱 Cross-platform (Android & iOS)
🚀 User Flow
Create or Join a Room
Share the room code with friends
Friends join the room
Select a presenter
Start screen sharing or play a video
Everyone watches together inside the app
Switch to Music Mode for synchronized listening
Automatically rotate the DJ or manually choose who plays next
