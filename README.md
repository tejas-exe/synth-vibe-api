# 🎵 Sync vibe

### Watch Together. Listen Together. Share Together.

SyncPlay is a real-time collaborative mobile application that lets friends create or join private rooms to enjoy videos, music, and screen sharing together — perfectly in sync, with a clean, modern, and distraction-free experience.

</div>

---

## ✨ Features

| | |
|---|---|
| 🎉 | Create or join rooms using a unique room code |
| 👥 | Unlimited participants (minimum 4 to start) |
| 📺 | Real-time screen sharing |
| 🎥 | Watch videos together inside the app |
| 🎵 | Synchronized music listening |
| 🎤 | Presenter selection |
| 💬 | Live chat & reactions |
| 🔄 | Automatic DJ rotation (Switch Mode) |
| 🎧 | Manual music mode |
| ⚡ | Low-latency synchronization |
| 🔐 | Private & secure rooms |
| 📱 | Cross-platform (Android & iOS) |

---

## 🚀 User Flow

1. Create or join a room
2. Share the room code with friends
3. Friends join the room
4. Select a presenter
5. Start screen sharing or play a video
6. Everyone watches together inside the app
7. Switch to Music Mode for synchronized listening
8. Automatically rotate the DJ, or manually choose who plays next

## 🎨 Design Philosophy

- **Modern & minimal** — media-first experience
- **Small, non-distracting** participant bubbles
- **One-handed usability**
- **Smooth animations**
- **Glassmorphism-inspired UI**
- **Dark theme** with vibrant gradient accents
